# Flip 7 Score

An unofficial score keeper for the Flip 7 card game. One phone keeps score for the table: add players, enter each round's score or bust, and it calls the winner after someone reaches 200. The rules and FAQ are built in.

Open **https://sgoodwin-cloud.github.io/flip7-score/** in Safari, tap Share, then **Add to Home Screen**. Open it once with signal and it works offline from then on.

Flip 7 is a game by Eric Olsen, published by The Op. This app isn't affiliated with them. Fonts: Overpass, Bebas Neue, Roboto Condensed and Yellowtail (SIL Open Font Licence) and Roboto (Apache 2.0), via Fontsource.
